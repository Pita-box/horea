Často kladené otázky

Svůj tarif můžete změnit kdykoliv v sekci 'Můj účet' -> 'Předplatné'. Změna se projeví okamžitě a případný rozdíl v ceně vám bude adekvátně vyúčtován.

Všechny vaše faktury jsou bezpečně uloženy v uživatelském panelu pod záložkou 'Historie plateb'. Můžete si je stáhnout ve formátu PDF.

Ano, poskytujeme 14denní garanci vrácení peněz bez zbytečných otázek. Stačí kontaktovat naši podporu přes formulář výše.

Horea nabízí robustní API a předpřipravené konektory pro oblíbené nástroje. Detailní dokumentaci najdete v sekci pro vývojáře.
